# Lizenznavigation

## Ziel

Der Link „Lizenz“ im Footer soll eine lesbare Wattspur-Seite öffnen. Nutzer
sollen nicht in einer rohen Markdown-Datei landen und nicht auf den
Browser-Zurück-Button angewiesen sein.

## Akzeptanzkriterien

- Der Footer verlinkt auf `lizenz.html`.
- Die Lizenzseite verwendet den gemeinsamen Wattspur-Kopf und -Fuß.
- Ein sichtbarer Link „Zur Startseite“ führt zu `index.html#top`.
- Die Lizenzseite ist auf Desktop und Tablet lesbar und hat eigene Meta-Daten.
- `lizenz.html` ist im Offline-Cache und in der Sitemap berücksichtigt.
- Die ursprüngliche `LICENSE.md` bleibt als technische Quelldatei erhalten.
