# Anforderungen: Einheitliche Drop-Ziel-Trefferflächen

## Ziel

Beim Ziehen soll ein gültiges Ziel schon knapp neben dem sichtbaren Objekt
erkennbar werden. Basiszähler, Kaskadenzähler, anlagenbezogene Zähler und
Anlagen verwenden deshalb dieselbe unsichtbare Reservefläche.

## Akzeptanzkriterien

- Die Reservefläche liegt etwa 0,65 rem außerhalb der sichtbaren Karte.
- Sie wird nur während eines aktiven Drag-and-Drop-Vorgangs interaktiv.
- Die sichtbare Objektgröße und alle Leitungskoordinaten bleiben unverändert.
- Das vorhandene Feedback für Anlagenzuordnung, Zählerkaskade und
  Positionswechsel bleibt fachlich unterscheidbar.
- Normale Klicks zum Öffnen der Objektinformationen werden nicht blockiert.
