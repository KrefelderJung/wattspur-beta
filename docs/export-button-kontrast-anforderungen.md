# Anforderungen: Kontrast primärer Aktionsbuttons

## Ziel

Die PDF-Exportbuttons und primären Dialogaktionen wie „Schließen“ müssen im
hellen und dunklen Modus klar lesbar sein. Jeder Button erhält eine sichtbare
Kontur, damit seine Fläche auch bei ähnlichen Hintergrundfarben eindeutig
erkennbar bleibt.

## Akzeptanzkriterien

- Der gefüllte Gesamtexportbutton verwendet im hellen Modus eine helle
  Schrift auf der dunklen Primärfläche.
- Im dunklen Modus bleibt die bisherige dunkle Schrift auf der hellen
  Primärfläche lesbar.
- Beide Exportbuttons besitzen eine sichtbare, thematisch passende Kontur.
- Die Anpassung verändert weder Exportfunktion noch PDF-Inhalt.
- Dialogaktionen wie „Schließen“ verwenden denselben kontrastreichen
  Primärbutton-Standard.
